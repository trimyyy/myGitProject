# Quiz Application - Features

1. **List Available Quizzes**
   * Displays all loaded quiz topics and titles stored in fixed-size arrays.

2. **Select and Start Quiz**
   * Prompts user to select a quiz index and loads corresponding questions and answer options.

3. **Interactive Question & Answer Loop**
   * Iterates through questions sequentially, prompts for multiple-choice input (A/B/C/D), and records player choices.

4. **Input Validation**
   * Validates menu selections and user choices using structured control flow (`if/else`, `switch`), re-prompting on invalid inputs.

5. **Score Calculation & Summary**
   * Evaluates correct answers, calculates total percentage score, and prints a final result summary.

6. **High Score Tracker**
   * Keeps track of student names and top scores using parallel arrays or record arrays within the session.
